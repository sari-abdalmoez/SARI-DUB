# SARI DUB v2 (مشروع جديد)

## التشغيل
1. افتح المجلد في Android Studio (Ladybug أو أحدث). سينشئ Gradle Wrapper تلقائياً.
2. Build > Run على هاتف أو محاكي بنظام Android 7+ (minSdk 24).

## ما هو مُنفَّذ
- **البحث الموحّد**: TMDB + TVMaze + Trakt بالتوازي، مهلة 6 ثوانٍ لكل مزود، إزالة التكرار، ترتيب حسب الصلة.
- **فهم العربي والإنجليزي**: تطبيع النص، توحيد الألف والتاء المربوطة، مطابقة الهيكل الصامت
  (مثال: "انترستيلر" و Interstellar يتطابقان تقريباً)، تحمل الأخطاء الإملائية، وفهم السنة والنوع (فيلم/مسلسل).
- **الاقتراحات الفورية** من النتائج السابقة.
- **Failover**: مزود بطيء أو معطّل لا يوقف البحث. الترند ينتقل من TMDB إلى Trakt تلقائياً.
- **التشغيل**: مصادر حقيقية فقط (Internet Archive - الملك العام). عند عدم وجود مصدر تظهر رسالة واضحة، ولا تُصنع روابط.
- **الترجمة النصية**: ملف SRT من المصدر يُترجم إلى العربية عبر Gemini بالدفعات ويُخزَّن مؤقتاً، ثم يُحمَّل في المشغل.
- **ترجمة المانجا**: Gemini يحدد الفقاعات والنص، ثم يُمحى النص الأصلي داخل الفقاعة بلون خلفيتها وتُكتب الترجمة مكانه.

## ما لم يُنفَّذ بعد (مذكور صراحة)
- **edge-tts والدبلجة الصوتية**: لم تُضف في هذا الإصدار.
- **ترجمة الفيديو بدون ملف ترجمة**: يحتاج تفريغاً صوتياً (ASR). هذه المرحلة القادمة.
- **فصل الموسيقى والمؤثرات**: لم يُنفَّذ بعد.

## ملاحظات أمان
- المفاتيح موجودة في `Config.kt`. بعد الاختبار انقلها إلى `local.properties` وأعد توليد المفاتيح إن شاركتها علناً.
- مفتاح Gemini بصيغة `AQ.` قد لا يعمل مع `x-goog-api-key`، لذلك يعيد الكود المحاولة بـ `Bearer` تلقائياً.
