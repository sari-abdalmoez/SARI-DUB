# SARI DUB (v2.2.0)

## الأسرار المطلوبة (لا تُكتب في الكود أبداً)
يمكن ضبطها داخل **الإعدادات** في التطبيق بعد التثبيت (تُحفظ في مساحة التطبيق الخاصة)، أو كـ Repository secrets لبناء APK مهيأ مسبقاً في GitHub Actions. لا تضع مفاتيح حقيقية داخل ملفات المصدر أو Git:

| الاسم | الاستخدام |
|---|---|
| `TMDB_KEY` | بيانات الأفلام والمسلسلات والمقترحات |
| `TRAKT_CLIENT_ID` | بحث Trakt (يُرسل في الهيدر `trakt-api-key`) |
| `GEMINI_KEY` | ترجمة المانجا والحوارات وملفات SRT |
| `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` | اختيارية: توقيع إصدار دائم |

TVMaze لا يحتاج مفتاحاً.

## البناء المحلي
1. للبناء المهيأ مسبقاً، انسخ `local.properties.example` إلى `local.properties` وضع القيم (اختياري إذا ستضيف المفاتيح من إعدادات التطبيق بعد التثبيت).
2. افتح المجلد في Android Studio، أو شغّل `gradle assembleRelease` بعد تثبيت Gradle 8.9.
3. الناتج: `app/build/outputs/apk/release/app-release.apk`.

بدون `KEYSTORE_FILE` يُوقَّع الإصدار بمفتاح debug، وهو قابل للتثبيت للتجربة. للتوزيع استخدم مفتاحاً ثابتاً، لأن تغيير مفتاح التوقيع يمنع التحديث فوق نسخة مثبتة سابقاً.

## CI
`.github/workflows/android-release.yml` يكتب الأسرار إلى `local.properties` من متغيرات البيئة، يبني APK، ثم يتحقق منه بـ `apksigner` و`aapt`.

## التشغيل ومفاتيح API
- إذا كانت GitHub Secrets فارغة، يظل APK قابلاً للبناء وتستطيع إدخال المفاتيح من الإعدادات بعد التثبيت؛ زر «حفظ وفحص المفاتيح» يختبر TMDB وTrakt وGemini بطلبات فعلية.
- لا يحتاج TVMaze وCinemeta إلى مفاتيح ويظلان بديلين للبحث عن بيانات العناوين.
- أُزيل Internet Archive كمصدر تشغيل؛ TMDB وTrakt لا يستضيفان ملفات الفيديو. تشغيل/ترجمة الفيديو المحلي ما زال متاحاً.

## ما هو مُنفَّذ
- الواجهة الفاتحة (الرئيسية) والداكنة (البحث والتفاصيل) بمكونات Compose أصلية.
- زر + يفتح ورقة سفلية فيها Video و Manga / Comic، وكلاهما يفتح منتقي الملفات الحقيقي.
- بحث بتأخير 350 ms، وتصفية (الجميع/أفلام/مسلسلات)، وبحث صوتي عبر محرك التعرف على الصوت في الجهاز.
- تصنيف الأخطاء: مفتاح مفقود/غير صالح، تجاوز الحد، مهلة، لا اتصال، استجابة غير متوقعة، خدمة متوقفة. تظهر السبب الفعلي للمستخدم.
- لا توجد حالياً مصادر بث أفلام خارجية مفعلة؛ لا تُعرض روابط تشغيل وهمية. تشغيل الفيديو المحلي منفصل.
- مقترحات من TMDB للعناوين القادمة من TMDB فقط.
- ترجمة الفيديو المحلي: تقطيع بدون إعادة ترميز، ثم Gemini للتفريغ والترجمة والانفعال، ثم Edge-TTS للدبلجة.
- ترجمة المانجا مع حفظ النتائج في Pictures/SariDub.

## قيود معروفة
- البحث في العناوين لا يضمن وجود مصدر بث للفيلم؛ لم نعد نستخدم Internet Archive كمصدر تشغيل.
- التزامن بين الدبلجة والفيديو يعتمد على طوابع Gemini الزمنية، وقد يكون فيه فرق بسيط.
- الدبلجة تستخدم بروتوكول Edge-TTS غير الرسمي، وقد تتغير هذه الخدمة من Microsoft.
- فصل الموسيقى والمؤثرات غير مُنفَّذ بشكل حقيقي؛ يُتجاهل الصوت غير الكلامي فقط في التفريغ.
- قد لا تتوفر مصادر تشغيل مرخّصة لكل عنوان. عندها تظهر رسالة واضحة.
